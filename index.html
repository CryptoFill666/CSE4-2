Каталог UI-елементів веб-інтерфейсу

Формат: HTML / CSS / JS
Стан прикладів: інтерактивні

01

Перемикачradiobutton

Дозволяє обрати лише один варіант із групи взаємовиключних опцій. Усі перемикачі однієї групи пов'язані між собою — вибір нового автоматично знімає попередній.

  • Використовується, коли варіант може бути лише один
  • Усі варіанти групи видно одразу, без розкриття списку
Приклад — рівень складності завдання
02

Прапорецьcheckbox

Дозволяє обрати кілька варіантів незалежно один від одного — кожен прапорець вмикається чи вимикається окремо, без впливу на сусідні.

  • Підходить для множинного вибору (теги, налаштування)
  • Може використовуватись і як самостійний перемикач "так/ні"
Приклад — технології у проєкті
03

Текстове полеtext input

Приймає та дозволяє редагувати текстові дані, введені користувачем: короткий рядок (input) або багаторядковий текст (textarea).

  • Основа будь-якої форми — реєстрація, пошук, коментарі
  • Може мати плейсхолдер, валідацію та підказку
Приклад — форма
04

Вкладкиtabs

Організовують вміст у окремі розділи, між якими можна перемикатись, клацаючи на заголовки. Показують лише один розділ за раз, приховуючи інші.

  • Зменшують візуальне перевантаження сторінки
  • Використовуються для пов'язаного, але роздільного контенту
Приклад — розділи профілю
Особисті дані користувача: ім'я, аватар, короткий опис.
Мова інтерфейсу, тема оформлення, сповіщення.
Зміна пароля, двофакторна автентифікація, активні сесії.
05

Кнопкаbutton

Запускає дію після натискання: відправку форми, збереження, видалення. Стиль кнопки зазвичай відображає важливість або наслідки дії.

  • Primary — головна дія на екрані
  • Secondary — допоміжна дія, danger — незворотна/ризикована дія
Приклад — дії форми
06

Текстова міткаtext label

Статичний текст, що описує поле, дає інструкцію або показує стан системи. На відміну від інших елементів, з міткою не можна взаємодіяти.

  • Підвищує доступність — пояснює призначення поля
  • Використовується для статусів: помилка, успіх, обов'язковість
Приклад — підписи та статуси
Електронна пошта * обов'язкове поле
Дані успішно збережено
07

Посиланняlink

Переносить користувача на іншу сторінку, розділ сайту або зовнішній ресурс. Візуально виділяється кольором та підкресленням, щоб бути впізнаваним.

  • Внутрішні посилання — навігація в межах сайту
  • Зовнішні посилання зазвичай відкриваються в новій вкладці
Приклад
Перейти до розділу "Radiobutton" (внутрішнє) Документація MDN (зовнішнє, нова вкладка)
08

Підказкаtooltip

З'являється при наведенні курсора на елемент і показує коротку додаткову інформацію, не займаючи постійного місця на екрані.

  • Використовується для пояснення іконок або скорочених назв
  • Не повинна містити критично важливу інформацію — лише допоміжну
Приклад — наведіть курсор
API-ключ Унікальний токен для доступу до сервера Статус Синхронізовано 2 хв тому
09

Випадний списокdropdown list

Дозволяє обрати один варіант зі списку, який за замовчуванням згорнутий і розкривається лише при кліку — економить місце порівняно з набором radiobutton.

  • Зручний, коли варіантів багато (країни, категорії)
  • Може підтримувати пошук або множинний вибір
Приклад — параметри запиту
Клік по полю розгортає список опцій; клавіші ↑ ↓ дозволяють гортати варіанти.
10

Таблиця данихdata grid

Показує табличні дані рядками та стовпцями з можливістю сортування, фільтрації та (опційно) редагування прямо в клітинках.

  • Використовується в адмін-панелях, звітах, списках записів
  • Часто доповнюється пошуком та пагінацією
Приклад — клік по заголовку сортує стовпець
